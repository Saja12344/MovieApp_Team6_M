# MovieApp Team 6

A Swift application for browsing or presenting movie content. The project includes SwiftUI views, an MVVM-oriented structure, persistence support, and an asset catalog.

## Tech stack

- SwiftUI
- Swift
- MVVM
- Core Data or local persistence

## Run locally

Open the project files in Xcode, select an iOS simulator, and press `⌘R`.

## Project structure

- `ContentView.swift` — primary view
- `MVVM/` — view models and related layers
- `Persistence.swift` — persistence setup
- `Assets.xcassets/` — images and app assets
